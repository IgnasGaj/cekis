# Progress

Sprint 1 local implementation is complete as of 2026-10-05. The complete roadmap, sprint prompt and all four PNG references were inspected.

Evidence: `npm ci`, fresh initial migrations in a dedicated `cekis_test` database, repeated `npm run db:migrate`, `npm run db:grant`, lint, typecheck, eight unit cases, five Playwright cases and production build passed locally. `tests/e2e/auth.spec.ts` captures a real Mailpit message and follows its link through the app. It covers first account creation, return access without duplicate users, two account separation, reload, invalid/replayed/expired links, concurrent consumption, session expiry, sign-out across tabs, external redirect rejection and send limiting under sequential and concurrent requests. The session also survived a manual Next.js server restart. A stopped SMTP catcher produced a failed send, and retry succeeded after it restarted. The non-Docker MailDev catcher accepted an SMTP message and served its inbox UI. Screens were visually inspected at 320, 390 and 1024 px; enlarged text produced no horizontal overflow. CI is defined at `.github/workflows/ci.yml` with disposable PostgreSQL and Mailpit services.

External mailbox delivery and real-device checks remain unrun. [GitHub Actions CI](https://github.com/IgnasGaj/cekis/actions/runs/37311577895) passed for implementation commit `ebc2cbc5597b35bf49709ee43494a7772e2eacfd`. `npm audit` currently reports 11 advisories (4 moderate, 7 high) in development/tooling dependencies including Drizzle Kit, MailDev and ESLint tooling; these need review before production hardening.
